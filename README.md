# FarmWaste360Expo

## Problem Statement

Agricultural waste is often underutilized, leading to environmental issues and loss of potential economic value. There is a lack of efficient systems to connect farmers with industries that can reuse this waste.

## Solution

FarmWaste360Expo is a React Native application that bridges the gap between farmers and industries by providing a platform to manage, track, and utilize agricultural waste efficiently.

## Tech Stack

* Frontend: React Native (Expo)
* Backend: Node.js
* Language: JavaScript

## Features

* User authentication for farmers and industries
* Separate dashboards for farmers and industries
* Waste management and tracking system
* API-based data handling

## How It Works

1. Farmers log in and list available agricultural waste
2. Industries browse and request required materials
3. The system facilitates efficient waste utilization

## Installation and Setup

1. Clone the repository:
   git clone https://github.com/Spandanamustur/FarmWaste360Expo.git

2. Navigate to the project folder:
   cd FarmWaste360Expo

3. Install dependencies:
   npm install

4. Run the project:
   npx expo start
